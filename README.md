# Dendy Satrio Wibowo — Data Analyst Portfolio

Personal portfolio website showcasing data analytics projects, skills, and background.

🌐 **Live Site:** [dendysatrio.github.io/Portofolio](https://dendysatrio.github.io/Portofolio)

---

## About

Built from scratch using vanilla HTML, CSS, and JavaScript — no frameworks.
Designed to present data analytics work in a clean, interactive format.

---

## Features

- Animated particle background with mouse interaction
- Project modal popups with key findings, image carousel, and direct links
- Smooth scroll reveal animations
- Fully responsive across desktop and mobile
- CV download button
